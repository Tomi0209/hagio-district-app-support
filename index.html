Account & Registration

Users create an account with name, email, and password. During registration, the app checks password strength and ensures that the two required consent statements are accepted:

  • The data is only used for account creation and app functionality.
  • The app is not therapeutic and does not replace professional care.

You can log out at any time using the “Today” page. You can delete your account through the Dashboard.

Using the App

Daily Reflection (“Today”)

Displays your daily impulse for reflection/action and basic progress information for the active program. You can add items to Favorites and log out from this page.

Dashboard

Shows all available fixed programs and lets you start a program. You can configure up to four daily push notifications (feature is currently being improved — an info text is shown in the app). The Dashboard also allows you to permanently delete your account.

Workbook

Premium users can access the integrated workbook PDF in German and English. If the viewer does not load correctly, a Reload button is available. The PDF can also be opened or exported externally.

Favorites

You can add Favorites directly from the Today page and remove them on the Favorites page. After saving at least 10 Favorites, Premium users can generate custom programs from them.

Program Generation

Free users can restart the same program after finishing it. Premium users can generate new programs after completing the current one.

Language Switching

You can switch the app language at any time via the flag icon in the bottom-right corner of every page.

FAQ – Frequently Asked Questions

Is there a “Forgot Password” option?

Not yet. If you lose access to your account, you can create a new one. Only minimal data is stored (email, encrypted password, favorites, program progress), so account recovery is not required for app usage.

The daily impulse is not loading. What should I do?

Try logging out and back in. A weak internet connection can also delay loading.

The workbook is blank or does not load.

Use the Reload button or export the PDF to open it in another app.

Why can't I create a new program?

Only Premium users can generate new programs. Free users can restart the same program after completion.

How do I delete my account?

You can delete it through the Dashboard. All stored data will be permanently removed.

Notifications are not working.

You can configure up to four reminders in the Dashboard. The notification system is currently being improved — the app displays an info message to users.
