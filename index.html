Account & Registration

Users create an account with email, and password. During registration, the app checks password strength and requires two confirmations:

  • Data is only used for account creation and app functionality.
  • The app is not therapeutic and does not replace professional care.

You can log out at any time using the “Today” page. Your account can be permanently deleted through the Dashboard.

Using the App

Daily Reflection (“Today”)

  • Shows your daily impulse for reflection/action.
  • Displays basic progress information for the active program.
  • Allows adding items to Favorites (Premium only).
  • Includes the logout option.

Dashboard

  • Shows all available fixed or individual (Premium only) programs and allows you to start a program.
  • You can set planned times for up to four daily push notifications (the notifications feature is not yet implemented; an info message in the app informs users about this).
  • Includes the option to permanently delete your account.

Workbook

Premium users can access the integrated workbook PDF in German and English.

  • If the viewer does not load correctly, a Reload button is available.
  • You can also choose to open or export the PDF externally.

Favorites

  • Premium users can add Favorites directly from the Today page.
  • Favorites can be removed from the Favorites page.
  • After saving at least 10 Favorites, Premium users can generate custom programs from them.

Program Generation

The app offers three types of programs:

1. Fixed Programs (available for all users)

  • These are predefined programs that all users can start.
  • Free users can start one fixed program at a time and—after completing it—can only restart the same program.
  • Premium users can start any fixed program and generate a new one after completion.

2. Individual Programs (Premium only)

  • Premium users can generate a personalized program by answering a short set of questions.
  • The program is tailored to the user’s answers and current focus areas.
  • Free users do not have access to individual programs.

3. Favorites-Based Custom Programs (Premium only)

  • After saving at least 10 Favorites, Premium users can generate a custom program based on their Favorite items.
  • Free users cannot use Favorites, so they cannot create these programs.

Language Switching

You can switch the app language at any time. A flag icon in the bottom-right corner of every page opens the language selection view.

FAQ – Frequently Asked Questions

Is there a “Forgot Password” option?

Not yet. If you lose access to your account, you can create a new one. Only minimal data is stored (email, encrypted password, favorites and program progress), so account recovery is not really required for app usage.

The daily impulse is not loading. What should I do?

Try logging out and back in. A weak internet connection can also affect loading times.

The workbook is blank or not loading correctly.

Use the Reload button or export the PDF to open it in another app.

Why can’t I create a new program?

Free users can only restart the same (fixed) program after finishing it. Premium users can generate new fixed, individual, or Favorites-based programs.

How do I delete my account?

You can delete your account through the Dashboard. All stored data will be permanently removed.

Notifications are not working.

You can set up to four planned reminders in the Dashboard. However, notifications are not yet implemented — an info message in the app informs users.
